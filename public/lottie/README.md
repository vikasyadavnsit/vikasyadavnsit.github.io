# Lottie Character Animations

Place Lottie JSON files here for the Talking Characters project.

| File | Character | Suggested search on lottiefiles.com |
|------|-----------|--------------------------------------|
| `cat.json` | Tomcat | "cat talking cartoon" |
| `dog.json` | Dog | "dog cute cartoon" |
| `parrot.json` | Parrot | "parrot bird cartoon" |
| `robot.json` | Robot | "robot talking" |
| `ghost.json` | Ghost | "ghost cartoon cute" |

If a file is missing, the app automatically falls back to an animated emoji.
